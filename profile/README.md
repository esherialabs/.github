# Esheria

**The legal operating layer for African markets, and the firms that work in them.**

Esheria turns African legal knowledge into usable software. LexChat supports
source-backed African legal research, while LegalOS helps firms and legal
teams run governed legal work across African markets.

## Developer tools

The Esheria Regulatory Intelligence API, CLI, Python client, and MCP server
provide global, citation-backed access to explicit published regulatory packs.
They preserve pack readiness, versions, citations, source context,
limitations, licensing boundaries, trace IDs, and human-review requirements.

## Public-interest technology

### SafeRide v0.5.8 Android testing preview

SafeRide provides private, on-device support workflows for safer journeys. The
current Android preview has completed physical-device testing for the full
model download, pause and resume, Wi-Fi changes, verification, restart
persistence, synthetic local-AI chat, clean installation, and upgrade.
